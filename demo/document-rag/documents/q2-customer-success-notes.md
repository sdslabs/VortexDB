# Q2 Customer Success Notes: Northstar Energy

**Meeting date:** 2026-05-20  
**Participants:** Elena Ruiz (Northstar), Priya Nair (Vortex), Omar Bell (Vortex)

## Customer feedback

Northstar values Aster’s offline telemetry recovery but wants a clear indication that an alarm is based on delayed data. Its operations team also asked for a site-level weekly alert-quality report and an API field that identifies backfilled events.

## Vortex commitments

- Provide a written root-cause analysis by May 22 and weekly follow-ups through June.
- Deliver an `is_backfill` field in the v2 telemetry API by July 15.
- Pilot the weekly alert-quality report for Northstar’s three battery sites in June.
- Apply a 30-day alerting credit to the June invoice.

Northstar will evaluate a Growth-to-Enterprise upgrade in August if the pilot demonstrates fewer false-positive escalations. Pricing questions should reference the current plan sheet, not the pre-April proposal.
