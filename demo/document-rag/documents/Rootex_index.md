# Welcome to Rootex’s documentation!
Rootex is a Windows based 3D multithreaded game engine written in C++ and powers an in-production game being developed at [SDSLabs](https://sdslabs.co) .
-
Issue Tracker: [http://github.com/sdslabs/rootex/issues](http://github.com/sdslabs/rootex/issues)
-
Source Code: [http://github.com/sdslabs/rootex](http://github.com/sdslabs/rootex)
